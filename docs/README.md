**边界提示：**`/api/shared/*` 的 Agent key 和空间授权只保护独立的共享记忆服务。旧聊天 runtime、`/api/memories` 和来源消息接口仍属于本地单用户数据域；它们尚未统一为多 Agent 身份隔离的聊天系统。个人聊天自动提取的候选先进入审核队列，批准前不会参与召回。具体行为以代码、API 文档和相应专题为准。
